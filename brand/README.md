# Clearmark logo

All files are 480 × 480 and well under 2 MB.

| File | Use |
| --- | --- |
| `clearmark-logo-480.png` | Main logo, transparent corners |
| `clearmark-logo-square-480.png` | Full square on the dark background, for avatars that crop to a circle |
| `clearmark-logo-square-480.jpg` | Same square, JPG (no transparency) |
| `clearmark-logo-480.webp`, `clearmark-logo-square-480.webp` | WebP versions of the two above |
| `clearmark-logo.svg`, `clearmark-logo-square.svg` | Vector sources, scale to any size |
| `clearmark-logo.ico` | Windows/browser icon, 16–256 px |

Colors: background `#0B0E1F`, gradient `#7F8CFF` → `#B57BFF` → `#3EE6E0` → `#F2CB7E`, check mark `#FFFFFF`.
